## Brand & Style

### Vision & Personality
The design system delivers an authoritative, hyper-efficient, and institutional-grade financial interface. Built for high-frequency operators, quantitative traders, and AI-orchestrated financial workflows, it projects uncompromising precision, speed, and structural stability. The aesthetic is unashamedly utilitarian, high-contrast, and dense—minimizing decorative distraction while accelerating situational awareness and rapid execution.

### Design Movement: Financial Cyber-Utilitarianism
This system rejects decorative trends like glassmorphic blurs, diffuse neomorphic pillowed depths, and arbitrary negative space. Instead, it pairs elements of **Cyber-Utilitarianism** and **High-Contrast Minimalism**:
- **Color-Block Elevation:** Depth is communicated strictly through precise stepped luminance offsets rather than ambient blur shadows.
- **Data-First Density:** Information hierarchy relies on razor-sharp 1px hairlines, tabular typographic alignments, and semantic color punctuation.
- **Hyper-Visible Focal Anchors:** The deep void of the canvas (`#0b0e11`) is punctuated by an electric gold anchor (`#fcd535`), ensuring primary interactive vectors and conversion nodes stand out unequivocally under time-sensitive trading conditions.

## Colors

### Canvas & Surface Architecture
The color hierarchy is anchored on deep, low-luminance dark canvas values that mitigate optical fatigue during prolonged analytical sessions while providing maximal contrast against tabular metrics and interactive nodes:
- **Base Canvas (`#0b0e11`):** The foundational substrate for high-density monitors, terminals, navigation bars, and marketing bands.
- **Card Surface Tier 1 (`#1e2329`):** The primary container background for order books, execution panels, trade histories, and modular analytical widgets.
- **Elevated Surface Tier 2 (`#2b3139`):** Used for nested containers, table header strips, control rail groups, and interactive hover planes.

### Semantic Trading Rules
Chromatic color is deployed with strict functional discipline:
- **Primary Electric Gold (`#fcd535`):** Reserved exclusively for core brand accents, top-level actions, balance callouts, and conversion pathways. Text on primary buttons is always invariant dark ink (`#181a20`).
- **Trading Up / Positive (`#0ecb81`):** Represents positive price delta, match success, long/buy action triggers, and safe protocol metrics. Never used as a generic card fill.
- **Trading Down / Negative (`#f6465d`):** Represents downward price shifts, liquidation zones, short/sell action triggers, and critical systemic warnings.
- **Information Blue (`#3b82f6`):** Dedicated to system notices, accessibility focus rings (`0 0 0 2px rgba(59, 130, 246, 0.5)`), and algorithmic status indicators.

## Typography

### Structural Separation: Prose vs. Tabular Computation
The typographic hierarchy implements an uncompromising dual-stack system designed to eliminate optical misinterpretation in critical execution environments:
1. **Structural & Prose Stack (Inter):** Applied across display banners, card headings, navigation items, descriptive documentation, and interactive button text. Inter delivers clean, neutral, and unobtrusive letterforms with exceptional hinting at small dimensions.
2. **Quantitative & Tabular Stack (JetBrains Mono):** Mandated for all numerical data, order book depths, asset yields, transaction hashes, ticker values, and AI telemetry metadata. Monospaced tabular alignment guarantees that vertically stacked figures in financial tables maintain column lock without horizontal jitter during real-time streaming updates.

### Optical Alignment & Letter Spacing
- Large headlines (`hero-display`, `display-lg`) leverage negative tracking (`-0.02em`) to bind headline units tightly on high-resolution widescreen monitors.
- Monospaced numerical tiers enforce `font-feature-settings: "tnum" 1` and explicit baseline alignment to guarantee vertical harmony when placed alongside standard body labels.

## Layout & Spacing

### 4px Baseline Grid & Spatial Rhythm
The layout operates on a strict **4px modular grid** where spacing is driven by information density rather than decorative blank space. 

- **Gutters & Spans:** Standard desktop editorial layouts utilize a 12-column grid with `1.5rem` (24px) gutters. Operational terminal layouts switch into dense mode (`0.5rem` / 8px gutters) to accommodate multi-pane charting, depth books, and order entry consoles simultaneously.
- **Asymmetric Desktop Split:** Standard financial dashboards enforce an **8/4 desktop column split**, dedicating the 8-column zone to charts, data grids, and telemetry logs, while reserving the 4-column right rail for order routing, automated rules, and execution buttons.
- **Component Padding Scale:**
  - `space-xxs` (4px): Micro offsets between currency badges and numerical deltas.
  - `space-xs` (8px): Dense vertical padding in market rows, input field groupings, and pill badges.
  - `space-sm` (12px): Compact table row padding, trade button inner vertical clearances.
  - `space-md` (16px): Standard container padding for utility cards, search controls, and toast notifications.
  - `space-lg` (24px): Primary outer card bounds, multi-asset portfolio summaries.
  - `space-xl` / `space-xxl` (32px / 48px): Major section dividing blocks and macro hero framing.

### Breakpoint Adaptation
- **Mobile (< 768px):** Single-column stacked layouts, horizontal scroll containers for dense data tables, `1rem` outer canvas padding, bottom-pinned execution sheets.
- **Tablet (768px – 1024px):** 2-column or tabbed multi-pane layouts, compressed horizontal menus.
- **Desktop (1024px – 1440px):** 12-column grid with fixed 64px header and synchronized multi-panel data feeds.
- **Ultra-Wide (> 1440px):** Full-bleed modular grid snapped up to maximum 1600px container or continuous 100% fluid operational canvas.

## Elevation & Depth

### Tonal Stratification (Zero-Shadow Rule)
Visual depth is established strictly through **luminance stepping** and **1px structural hairlines**. Traditional diffuse drop shadows are barred from operational surfaces, as they degrade legibility and soften the crisp delineation required for rapid data scanning.

1. **Floor Canvas (`#0b0e11`):** Level 0 baseline substrate. Everything sits anchored against this infinite dark ground.
2. **Elevated Container (`#1e2329`):** Level 1 surface. Cards, market tables, filter bars, and modal bodies elevate +18 in luminance over the canvas.
3. **Internal Nested Plinth (`#2b3139`):** Level 2 surface. Secondary inputs, nested data grids, active navigation indicators, and table header strips.
4. **Structural Separation:** Panels are demarcated with crisp 1px borders using `#2b3139` (hairline dark) or `#474d57` (active/hover divider).
5. **Interactive Focus & Elevation:** Floating popovers and dropdown menus maintain `#1e2329` fill with a sharp 1px outline in `#474d57` and a high-focus blue containment glow `box-shadow: 0 0 0 2px rgba(59, 130, 246, 0.5)` when actively toggled.

## Shapes

### Controlled Compact Geometry
The system enforces geometric discipline using **Soft (Level 1)** corner radii to maintain a high-density architectural profile. Softer curves are restricted purely to isolated interaction tokens:

- **Micro Controls & Buttons (`0.25rem` / 4px):** Compact trading buttons (`Buy / Long`, `Sell / Short`), small input steppers, and inline tag containers.
- **Standard Controls & Inputs (`0.375rem` / 6px):** Primary form fields, standard CTAs, dropdown triggers, and modal dialogs.
- **Structural Cards (`0.5rem` / 8px):** Primary card panels and modular container boundaries (`rounded-lg`).
- **Major Banner Surfaces (`0.75rem` / 12px):** Macro marketing cards and hero promo cards (`rounded-xl`).
- **Conversion Pills & Avatars (`9999px`):** High-priority standalone action triggers (`button-primary-pill`), status beacon dots, and token crypto asset icons.
