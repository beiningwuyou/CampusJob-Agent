## 一、概述与商业化战略定位

### 1.1 商业背景与设计哲学
高校毕业生在校招与公考备战期，面临**“信息严重过载、跨源碎片化、格式杂乱（海报/附件）、缺乏精准契合度研判”**四大痛点。

在产品商业化演进中，团队遵循以下两大核心战略原则：
1. **用户增长与口碑飞轮（Product-Led Growth, PLG）**：
   - 求职是高焦虑、短周期、极度依赖同学圈层推荐的场景；
   - 必须提供一个**“开箱即用、零干扰、无套路”的免费基础版**，满足本校宣讲、头部大厂、招考官方等最高频的“信息确定性”诉求，建立信任基石。
2. **端云协同与隐私安全护城河（Local-First + Cloud-Curated Intelligence）**：
   - **数据与算力上云**：全网多源爬虫、微信推文/长图海报多模态 OCR、附件表格解析是高算力、高维护成本、高防爬对抗的环节，由云端服务器集中算力统一清洗；
   - **隐私与个性化在端**：用户的真实姓名、手机、政治面貌、GPA、完整简历等敏感隐私**绝对不出本地**；云端将结构化职位流下发到客户端后，由端侧 Agent 完成个性化简历匹配、雷达图计算与考公资格排查。

## 四、端云协同技术架构与数据流向

### 4.1 架构设计原理（Local-First + Cloud-Push）
为了兼顾**高并发采集的稳定性**与**求职者简历的极致隐私安全**，付费版采用创新的**端云分工协同模式**：

```mermaid

    subgraph 云端服务端 [Cloud Server (SaaS 数据服务中心)]
        C1[全网多源异步爬虫引擎: 100+高校/全省考公/名企] --> C2[多模态视觉感知与 OCR 矩阵]
        C2 --> C3[双 Schema 结构化清洗 & 实体指纹去重]
        C3 --> C4[(云端每日精选全网岗位库)]
        C4 --> C5[增量岗位同步服务 (Cloud Feed Pusher)]
    end

    subgraph 客户端本地运行环境 [Client Application (本地隐私安全沙箱)]
        direction TB
        C5 -.->|每日定时下发纯公共岗位数据包| L1[本地增量岗位同步接收器]
        L1 --> L2[(本地 SQLite 数据库)]
        
        subgraph 免费版链路 [免费版轻量链路]
```

### 4.2 数据流向与安全合规
1. **云端下行数据（Server → Client）**：
   - 仅包含**公开的招聘公告、JD 内容、企业信息、宣讲时间、报名链接**；
   - 绝不收集、不存储、不传输任何用户的客户端设备唯一标识、个人画像或简历信息；
   - 支持差分增量下发（每天仅下发当日新增/变更的数百条精选岗位，网络传输 ≤ 2MB）。
2. **端侧计算与脱敏闭环（Client Local Processing）**：
   - 用户的学校、专业、学历、毕业年份、求职偏好、简历原文**100% 存储于本地 SQLite**；
   - 岗位与用户的向量检索、相关性排序在客户端本地完成；
   - 若调用公网 LLM 算力进行深度简历润色，先经本地正则表达式与命名实体识别（NER）脱敏替换为代号，仅回传无个人身份特征的纯语义文本。

## 五、商业化付费体系与转化漏斗设计

### 5.1 商业化收费模式（建议方案）

| 模式 | 定价策略（参考区间） | 适用场景 | 用户价值锚点 |
| :--- | :--- | :--- | :--- |
| **单月冲刺卡** | ¥19.9 ~ ¥29.9 / 月 | 秋招提前批、秋招冲刺期（9-11月）、春招备战期（3-4月） | 1 杯奶茶钱，换取整月全网信息免搜寻与精准 DDL 护航 |
| **季度备考卡** | ¥49.9 ~ ¥69.9 / 季 | 国考/省考集中备考周期（9月至次年1月） | 覆盖公告发布、报名自查、笔试准考证全周期 |
| **校招全季通过卡（年卡）**| ¥99 ~ ¥149 / 年 | 应届毕业生整个学年（从大四/研二研三入学至次年毕业离校） | 一站式贯通秋招、春招、国省考、事业单位、实习全链路 |

### 5.2 引导升级触点（Conversion Triggers）
系统在免费版中设置自然、克制且高吸引力的付费转化触点，绝不弹窗打扰用户，而在用户需要深度决策的关键节点提供明确升级提示：

1. **自定义信源受限触点**：
   - 当免费用户在 `/settings` 尝试添加第 2 所学校或非白名单企业链接时，弹出优雅提示：
     > *“当前为免费版，支持本校与官方白名单信源。升级 Pro 版即可解锁全网 100+ 高端高校源、央国企直通车及无限量自定义 RSS。”*
2. **岗位详情契合度锁闭触点**：
   - 免费用户查看岗位详情时，基础信息（公司/薪资/地点/要求）完全可见，但右侧「AI 契合度评分」与「简历差距诊断报告」显示毛玻璃模糊效果，配有轻量引导文案：
     > *“解锁 Pro 版即可查看与您简历的契合度评分（0-100分）、六维能力雷达与针对性面试押题。”*
3. **海报极速解析额度触点**：
   - 免费用户每月享有 3 次长图海报/推文免费试用解析；超出后提示升级 Pro 版无限次使用。
4. **考公资格自查锁定触点**：
   - 免费版公考岗位仅展示招考公告正文，附件岗位表提示：
     > *“Pro 版专享：自动提取 500+ 岗位 Excel 并基于您的专业/应届/党员身份执行一键合规自查，防误报漏报。”*

## 六、异常降级与体验边界

1. **付费到期降级策略**：
   - 用户订阅到期后，系统自动平滑降级至免费版，不删除用户本地已沉淀的历史岗位数据与个人画像；
   - 停止接收云端每日精选岗位流，保留用户最初绑定的 1 所高校及基础白名单源的本地抓取；
   - 本地历史已生成的匹配报告依然可查，新岗位不再触发 Agent 深度匹配。
2. **云端服务不可用时的容灾**：
   - 若云端推送服务器短时故障（如维护或网络波动），付费客户端自动无缝降级为**本地直连模式**（调度本地内置爬虫与本地 Agent 继续工作），绝不出现白屏或空数据阻塞。
